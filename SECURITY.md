# Security Policy

Sniff4Hound is a packet capture tool. Use it only on networks, hosts, and interfaces where you have explicit authorization.

## Reporting issues

- For responsible disclosure, open a private security advisory in the repository.
- Include the affected version, interface details, and a minimal reproduction path.
- Do not include credentials, personal data, or captured payloads unless strictly necessary.

## Provenance and data hygiene

- Do not publish captured traffic, secrets, private certificates, or customer identifiers in issues or pull requests.
- Preserve authorship, copyright, and license notices when fixing vulnerabilities.
- If a report involves unauthorized copying, impersonation, or repository misuse, document the affected files, commits, and public URLs precisely so the maintainer can react quickly.
